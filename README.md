# Woof

Woof is the agent-development and orchestration layer for Herdr. A coding agent
uses Woof to delegate work, run workflows, and receive artifacts and structured
results. `HerdrAgentsSDK` coordinates the work; Herdr runs the agents.

This checkout is a project shell. The SDK and workflows described here are the
target design, not available features. Start with the [documentation index](docs/README.md)
and [product brief](docs/product/brief.md).
