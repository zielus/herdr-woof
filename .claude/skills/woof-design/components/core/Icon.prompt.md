```jsx
<Icon name="terminal" size={16} />
```

Names: play, square, x, check, copy, chevronDown, chevronRight, search, refresh, sun, moon, file, terminal, externalLink, alert, info, menu, github, clock, hash, arrowRight, dot. Inherits `currentColor`.
